# أنتيمك — معاينة الصفحات (Mock, ver.6)

واجهة عرض بصري بس (بدون سيرفر أو قاعدة بيانات أو دفع حقيقي)، عشان تتفرج على شكل أول 5 صفحات من الكتاب لايف على موبايلك.

## إزاي ترفعها على GitHub Pages (بالظبط زي الخطة في سكشن 10)

1. اعمل ريبو جديد على GitHub باسم **anteemak-ui** (Public).
2. ارفع كل الملفات اللي في المجلد ده (`index.html`, `login.html`, ... ومجلد `assets/`) في **جذر الريبو مباشرة** — مش جوه مجلد فرعي.
   - أسهل طريقة من غير Git خالص: ادخل الريبو على GitHub → **Add file → Upload files** → اسحب كل الملفات والمجلد `assets` → **Commit changes**.
3. روح **Settings → Pages**.
4. تحت **Build and deployment → Source** اختار **Deploy from a branch**.
5. اختار الفرع **main** والمجلد **/(root)** → **Save**.
6. استنى دقيقة، هيديك لينك شكله كده:
   `https://<اسم-حسابك>.github.io/anteemak-ui/`
7. افتح اللينك من موبايلك — دي نفس تجربة أي حد هيزور الصفحة.
