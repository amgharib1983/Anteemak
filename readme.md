# 📘 منصة أنتيمك (Anteemak UI)

**المرجع التشغيلي وواجهات المستخدم الحية لمرحلة الـ MVP**

منصة "أنتيمك" (Anteemak) هي منصة تواصل اجتماعي وتعارُف قائمة على الثقة والاقتصاد الشفاف (Intent & Unit-Economics Social Discovery Platform).

---

## 🎨 الهوية البصرية والتصميم
* **الخلفيات الأساسية:** `#FAF8F5` (أوف وايت / بيج فاتح دافئ)
* **الكروت والواجهات:** `#FFFFFF` مع حدود `#E8E3D9`
* **اللون الأساسي:** `#00A8FF` (أزرق سماوي للثقة والأمان)
* **الإشارات الإيجابية:** `#34C759` (للتوثيق والأرباح)
* **التنبيهات والهدايا:** `#FF3B30` (للتنبيهات والأعلام)

---

## 📱 الصفحات التفاعلية الـ 5 (PWA MVP)

يحتوي التطبيق الحالي في ملف `index.html` على الواجهات التالية المجهزة للموبايل (Mobile-First):

1. **🔑 صفحة الدخول (Login Page):** تسجيل الدخول عبر OTP / واتساب أو شبكات التواصل.
2. **📝 صفحة بناء البروفايل (Onboarding):** إدخال البيانات المتقدمة وتوليد الأفاتار الكاريكاتيري تلقائياً.
3. **👤 صفحة البروفايل و Blur Matrix:** مع إمكانية معاينة واجهة الشاري، البائع (أرباح الكاش)، ولوحة الأدمن.
4. **💎 متجر النقاط (Point Store):** الباقات الـ 6 المعتمدة مع توضيح السعر المرجعي.
5. **🎁 كتالوج الهدايا (Gifts Catalog):** هدايا الواجب والمجاملات الـ 100 مع التكلفة بالنقاط والصافي الكاش.

---

## 🚀 كيفية التشغيل والرفع

### التشغيل المحلي:
افتح ملف `index.html` في أي متصفح مباشرة على جهازك أو من خلال الموبايل.

### الرفع على GitHub Pages:
1. ارفع كافة الملفات الموجودة في المستودع (`index.html`, `README.md`, `sitemap.xml`, `robots.txt`, `.nojekyll`).
2. اذهب إلى إعدادات المستودع (Settings) ➔ Pages.
3. اختر الـ Source على **`main`** أو **`master`** ثم احفظ.
4. سيتم نشر موقعك فوراً على الرابط الخاص بك.
